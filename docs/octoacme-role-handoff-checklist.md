# OctoAcme — Role Handoff Checklist

## Purpose
Use this checklist whenever work moves from one lifecycle phase to the next or when a major scope or release decision needs to be recorded.

## Lifecycle Handoff Checklist

### Initiation → Planning
- [ ] Product Manager has documented the problem statement, success metrics, and initial scope.
- [ ] Project Manager has confirmed stakeholders, milestones, and the kickoff plan.
- [ ] Technical Lead and UX / UI Designer have captured major feasibility or discovery questions.
- [ ] Open decisions have a named owner and target resolution date.

### Planning → Execution
- [ ] Prioritized backlog is ready with acceptance criteria and named owners.
- [ ] Engineering Manager has confirmed capacity and staffing assumptions.
- [ ] QA / Testing has reviewed the validation approach for the planned increment.
- [ ] Security / Compliance review needs are scheduled if the change is sensitive.

### Execution → Release
- [ ] Developers and QA / Testing have documented test evidence and known issues.
- [ ] Technical Lead has confirmed deployment and rollback expectations.
- [ ] Project Manager has a final status summary with unresolved risks called out.
- [ ] Customer Support / Enablement has release notes, FAQs, or support guidance.

### Release → Retrospective
- [ ] Customer-facing and internal release communications have been sent.
- [ ] Support issues, incidents, and adoption signals have been summarized.
- [ ] Product Manager and Project Manager have captured any scope or priority follow-ups.
- [ ] Retrospective attendees, agenda, and improvement proposals are prepared.
